# WPF Vector DB LLM Assistant

WPF 桌面端 RAG 助手，向量数据库与 LLM 集成实现。仓库内文档为脱敏合成数据，不包含客户资料与密钥。

## 功能
- 文档导入与切分
- 嵌入生成
- 向量库写入与检索
- LLM 回答与引用来源
- 配置管理（密钥走环境变量/本地安全存储）

## 技术栈
C# / .NET、WPF、向量数据库（按实际实现）、OpenAI 兼容 LLM API

## 快速开始
1. Visual Studio 打开解决方案
2. 配置向量库与 LLM 服务地址
3. 导入输入文档后提问

## 安全与合规
- 输入文档为脱敏合成数据
- 不提交真实 API Key
- 不包含客户资料
